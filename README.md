# Kreativt Webprosjekt - Årstider

Et interaktivt webprosjekt fra (Høst 2024).

## Om prosjektet
Temaet for prosjektet var "Årstider". Løsningen er en kreativ og interaktiv HTML/CSS-side hvor brukeren kan utforske de fire årstidene gjennom klikk og hover-effekter.

## Kode
- HTML
- CSS (inkludert animasjoner)

## Begrensninger
Prosjektet ble utviklet uten bruk av JavaScript, rammeverk eller eksterne biblioteker – kun ren håndkodet HTML og CSS.
